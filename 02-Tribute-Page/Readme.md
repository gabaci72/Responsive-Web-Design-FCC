# Tribute Page

## Overview

This project is a tribute page built as part of the freeCodeCamp's Responsive Web Design Certification. The tribute page is designed to honor a significant figure and includes various elements to showcase their achievements and contributions.

## Features

- **Responsive Design**: Ensures the tribute page looks good on all devices.
- **Informative Content**: Provides detailed information about the honored figure.
- **Visual Elements**: Includes images, videos, and other media to enhance the visual appeal.

## Technologies Used

- **HTML5**: For structuring the tribute page.
- **CSS3**: For styling the tribute page and making it responsive.

## How to Use

1. **Clone the Main Responsive Project Repository**:

   ```bash
   git clone https://github.com/gabaci72/Responsive-Web-Design-FCC.git
   ```

2. **Navigate to the Tribute Page Project Directory**:

   ```bash
   cd 02-Tribute-Page
   ```

3. **Open the `index.html` File**:
   Open the `index.html` file in your web browser to view the tribute page.

## File Structure

- `index.html`: The main HTML file containing the structure of the tribute page.
- `styles.css`: The CSS file containing the styles for the tribute page.
