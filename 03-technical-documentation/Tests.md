# Build a Technical Documentation Page

## Tests

- [x] 1. You should have a main element with an id of main-doc.
- [x] 2. You should have at least five section elements with a class of main-section.
- [x] 3. All of your .main-section elements should be section elements.
- [x] 4. You should have at least five .main-section elements that are descendants of #main-doc.
- [x] 5. The first child of each .main-section should be a header element.
- [x] 6. None of your header elements should be empty.
- [x] 7. All of your .main-section elements should have an id.
- [x] 8. Each .main-section should have an id that matches the text of its first child, having any spaces in the child's text replaced with underscores (_) for the id's.
- [x] 9. You should have at least 10 p elements (total) within your .main-section elements.
- [x] 10. You should have at least five code elements that are descendants of .main-section elements.
- [x] 11. You should have at least five li elements that are descendants of .main-section elements.
- [x] 12. You should have a nav element with an id of navbar.
- [x] 13. Your #navbar should have exactly one header element within it.
- [x] 14. You should have at least one a element with a class of nav-link.
- [x] 15. All of your .nav-link elements should be anchor (a) elements.
- [x] 16. All of your .nav-link elements should be in the #navbar.
- [x] 17. You should have the same number of .nav-link and .main-section elements.
- [x] 18. The header element in the #navbar should come before any link (a) elements also in the #navbar.
- [x] 19. Each .nav-link should have text that corresponds to the header text of its related section (e.g. if you have a "Hello world" section/header, your #navbar should have a .nav-link which has the text "Hello world").
- [x] 20. Each .nav-link should have an href attribute that links to its corresponding .main-section (e.g. If you click on a .nav-link element that contains the text "Hello world", the page navigates to a section element with that id).
- [x] 21. Your #navbar should always be on the left edge of the window.
- [x] 22. Your Technical Documentation project should use at least one media query.
