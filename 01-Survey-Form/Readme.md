# Survey Form

## Overview

This project is a survey form built as part of the freeCodeCamp's Responsive Web Design Certification. The form includes various input fields, real-time validation, and dynamic features to enhance the user experience.

## Features


- **Responsive Design**: Ensures the form looks good on all devices.

## Technologies Used

- **HTML5**: For structuring the form.
- **CSS3**: For styling the form and making it responsive.


## How to Use

1. **Clone the Main Responsive Project Repository**:
   ```bash
   git clone https://github.com/gabaci72/Responsive-Web-Design-FCC.git
   ```

2. **Navigate to the Survey Form Project Directory**:
   ```bash
   cd survey-form
   ```

3. **Open the `index.html` File**:
   Open the `index.html` file in your web browser to view and interact with the survey form.

## File Structure

- `index.html`: The main HTML file containing the structure of the survey form.
- `styles.css`: The CSS file containing the styles for the survey form.
